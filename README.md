# C Calculator
A simple calculator program written in C as part of my journey to learn programming.

## Features

* Addition
* Subtraction
* Multiplication
* Division

## Language

C

## How to Run

1. Compile the program using a C compiler.
2. Run the generated executable.
3. Enter the numbers and select the desired operation.

## Learning Objectives

* Understanding variables and data types
* Taking user input
* Using arithmetic operators
* Implementing conditional statements or switch cases
